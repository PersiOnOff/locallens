# LocalLens v0.1.0 — Your knowledge. Your machine.

The first public version of LocalLens brings private documents into a local
workspace: upload a file, ask a question, then follow the answer back to its source.

## What's included

- PDF, Markdown, UTF-8 text and common source-code files.
- Local Ollama embeddings and chat through Microsoft.Extensions.AI/OllamaSharp.
- Streamed answers with clickable retrieved passages and PDF page/text line references.
- SQLite persistence, background indexing, retry and source deletion.
- Local repository imports and a graph of relative imports/document links.
- Light and dark themes, including theme-aware code blocks and graph colors.
- Docker Compose startup and persistent data/model volumes.

## Try it

```sh
git clone https://github.com/PersiOnOff/locallens.git
cd locallens
docker compose up --build
```

Open **http://localhost:8080**. The first launch downloads the container images and
the `qwen2.5:3b` and `nomic-embed-text` models. After the models are ready, upload a
document or import `.` to try the fictional sample library.

## Before you use it

This is an initial, single-user local release, not a public multi-user service.
There is no application authentication. Keep the default localhost binding.
Scanned PDFs require external OCR; original PDF binaries are not retained.
Imports are snapshots, and graph links are resolved heuristically. Model-generated
citations point to retrieved passages but do not prove every claim is correct.

The default configuration processes documents locally. Initial downloads require
internet. A custom remote Ollama endpoint receives your queries and retrieved text.

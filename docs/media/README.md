# LocalLens media

All application screenshots were captured from the actual local Docker deployment
on 2026-11-10. The library contains only the fictional `policy.md` and `welcome.md`
samples. Answers were generated by local `qwen2.5:3b` using `nomic-embed-text`
retrieval. No UI content or model answers were fabricated for these screenshots.

| File                                    | Use                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `social-preview.png`                    | 1280 × 640 opaque PNG, below GitHub's 1 MB limit; branded composition with real screenshot thumbnails     |
| `demo.gif`                              | Edited keyframe walkthrough of the real upload/chat/source/theme/graph session; timing is for readability |
| `light-chat.jpg`, `dark-chat.jpg`       | Same conversation in both themes                                                                          |
| `light-welcome.jpg`, `dark-welcome.jpg` | Actual welcome screen in both themes                                                                      |
| `source-preview.jpg`                    | Retrieved source passage, line range and similarity display                                               |
| `file-graph.jpg`                        | The resolved Markdown link between the two samples                                                        |

`themes.jpg` is a side-by-side composition of the actual light/dark conversation
screenshots, suitable for sharing a comparison.

The social image adds a decorative frame and brand typography around the original
screenshots. It is artwork for the repository, not a screenshot of an extra screen.
The application screenshots keep the browser's captured layout; at this width,
opening a source uses the responsive overlay.

are bundled. Do not substitute private library content when refreshing public images.
